# docs/handoff — обмін завданнями між ChatGPT і Claude

> Статус: **чернетка до схвалення власником** (PR #1). Протокол почне діяти після злиття.

ChatGPT і Claude не бачать чатів одне одного. Спільне місце для них — цей репозиторій:
тут лежать черга, завдання, результати й рев'ю, щоб власник не копіював файли між чатами.

## Файли

| Файл | Що в ньому |
|---|---|
| [`PROTOCOL.md`](PROTOCOL.md) | ролі, гілки, PR, заборони, уникнення конфліктів, обов'язкові перевірки |
| [`QUEUE.md`](QUEUE.md) | черга завдань із `MASTER_TASKS.md` (статуси не змінено) |
| [`TASK_TEMPLATE.md`](TASK_TEMPLATE.md) | шаблон опису завдання |
| `tasks/Q-xxx.md` | описи конкретних завдань (з'являться після погодження) |

## Коротко

1. Завдання погоджує власник → 2. виконавець працює в окремій гілці й відкриває чернетку PR у
`hardening/security-mobile` → 3. тести й докази в PR → 4. рев'ю другим агентом → 5. зливає лише власник.

Жодних прямих змін у `main`, жодних змін Supabase без окремого дозволу, жодних секретів у репозиторії.
