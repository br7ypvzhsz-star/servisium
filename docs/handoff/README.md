# docs/handoff — обмін завданнями між ChatGPT і Claude

> Статус: **чернетка / тест доступу** (гілка `collab/access-probe`). Протокол ще не діє.

## Призначення

ChatGPT і Claude не бачать чатів одне одного. Спільне місце для них — цей репозиторій.
Папка `docs/handoff/` буде «поштовою скринькою»: тут лежать завдання, результати та рев'ю,
щоб власник проєкту не копіював файли між чатами вручну.

## Як це працюватиме (план)

1. **Завдання** — окремий файл `docs/handoff/T-xxx.md` (або GitHub Issue) з полями:
   виконавець (`claude` / `chatgpt`), статус (`todo` · `in_progress` · `review` · `done` · `blocked`),
   опис, критерії готовності.
2. **Виконання** — лише в окремій гілці (`claude/T-xxx`, `chatgpt/T-xxx`) і через Pull Request.
3. **Результат** — дописується у файл завдання (розділ «Результат» з доказом) і в `docs/CHANGELOG.md`.
4. **Рев'ю** — інший агент перевіряє PR і залишає коментар.
5. **Злиття** — лише власник (Ян). Агенти PR не зливають.

## Незмінні правила

- Жодних прямих змін у `main` (захищено правилом репозиторію).
- Жодних змін Supabase (міграції, SQL, дані) без окремого дозволу власника.
- Жодних секретів, PIN, ключів чи персональних даних — репозиторій публічний.
- Не змінювати налаштування GitHub, секрети та GitHub Actions без дозволу.
